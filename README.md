# HPC I/O Performance Analysis

Training materials for the **HPC I/O Performance Analysis Workshop**, organized by **NHR South-West (NHR@SW)** at Johannes Gutenberg University Mainz.

This three-day online workshop introduces parallel I/O and storage concepts, discusses I/O best practices, and provides hands-on experience with **Darshan** and **DFTracer**. Participants learn to characterize application I/O behavior, identify common performance problems, and analyze HPC workloads using profiling and tracing tools.

## Topics

- Introduction to parallel I/O and storage
- I/O best practices
- Application I/O characterization with Darshan
- I/O profiling and tracing with DFTracer

## Prerequisites and system access

Participants should have a basic understanding of the command line and Slurm.

Eligible participants from German universities receive guest access to **Mogon NHR** for the hands-on sessions. Please follow the account and preparation instructions provided by the organizers.
